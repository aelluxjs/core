# Aellux 0.1.0 Beta

**Status:** In development  
**Target version:** `0.1.0-beta.1`

## Objective

Deliver the first testable Aellux release as a Bootstrap-compatible library for loading and managing modular UX behaviors through Aellux Extensions.

## Required

- [ ] Stabilize the ES5-compatible Aellux boot script.
- [ ] Validate the `basic` and `full` runtime modes.
- [ ] Finalize the Extension lifecycle: `init`, `mount`, `unmount`, and `destroy`.
- [ ] Validate lazy Extension loading and declarative `aellux-ext` links.
- [ ] Validate intended interoperability with Bootstrap styles and utilities.
- [ ] Complete public API and core Extension documentation.
- [ ] Review the Extension scaffold and experimental examples.
- [ ] Add repeatable browser integration tests for the primary runtime flows.

## Acceptance Criteria

- [ ] `npm run build` completes without errors.
- [ ] Generated distribution files and source maps are synchronized with `src/`.
- [ ] The Aellux boot script selects the modern runtime or legacy fallback correctly.
- [ ] `basic` mode loads only registered Extensions.
- [ ] `full` mode initializes all core Extensions.
- [ ] Core Extensions can load and fail independently without blocking readiness.
- [ ] DOM controllers consistently apply the `mount` and `unmount` contract.
- [ ] Adaptive CSS is generated from the Adaptive Extension configuration.
- [ ] Bootstrap and Aellux namespaces do not conflict in the documented scenarios.
- [ ] README, examples, templates, license, and changelog are ready for publication.

## Out of Scope

- Complete implementation of the legacy runtime.
- Promotion of experimental components into the core bundle.
- A stable `1.0.0` API guarantee.
- Packaging Bootstrap or other third-party UI frameworks with Aellux.

## Release Checklist

- [ ] Resolve all required milestone items.
- [ ] Move delivered changes from `Unreleased` into the beta release section of `CHANGELOG.md`.
- [ ] Set the package version to `0.1.0-beta.1`.
- [ ] Run the complete build and integration tests.
- [ ] Verify package contents before publishing.
- [ ] Create the Git tag `v0.1.0-beta.1`.
