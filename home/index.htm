03 ▪ Your first behavior

Start with HTML.

Load the runtime. Describe a behavior. Keep your own visual design.

Browser

<script src="../dist/aellux.min.js"></script>
<script>
    $ae.init({ mode: "full" });
</script>

This path uses this repository’s public distribution. Keep the generated dist/ files together when deploying: the boot script loads the matching runtime, styles and Extensions.

npm

npm install @aelluxjs/core

Serve the package’s dist/ directory as public assets and use the browser boot script to initialize the runtime. Modules can also import the shared API:

import AelluxJs from "@aelluxjs/core";

AelluxJs.attr("preference");

04 ▪ The toolkit

Primitives to compose.
Extensions to add.

Build components and new behaviors with bundled primitives. Add optional navigation, environment and compatibility Extensions when your interface needs them.

Full includes all Core primitives automatically, but does not bundle every Core Extension. Optional Extensions load separately on demand. Stability is marked independently; Extensions without an Unstable label are stable.

Bundled primitives

All ten primitives are included automatically in Full. Compose them to build components and new behaviors; Preference and State Navigation initialize at startup, while the others initialize when needed.

06 ▪ Brand assets

Take aellux.js with you.

The æ symbol pairs Bootstrap warning yellow with dark lettering, just like the mark above. The logotype uses Geist from Google Fonts: a 650-weight name and a lighter, 400-weight .js suffix. Its text follows the same light or dark color as the page.

Keep clear space of at least one quarter of the symbol’s width around the brand. Both variants include this transparent margin for composition. The SVGs default to light and adapt automatically to the Bootstrap or AelluxJS dark theme.

Download the symbol or the symbol with logotype as SVG or PNG. Exports preserve the current colors, Geist typography and transparent clear space; the SVG includes its font.
