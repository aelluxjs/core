# Extension composition review

Reviewed on `update/beta.10` from `321cef0`, after the `829400f` snapshot cited in the supplied report. This review covers shared transforms, Snap geometry and AJAX lifecycle/history integration.

## Findings and changes

| Combination | Evidence and resulting behavior |
| --- | --- |
| Anchor + Feedback | Browser reproduction confirms that replacing Feedback keyframes displace the positioned Anchor. Diagnostic `2033` identifies the resolved target and transform writers. Positioning remains on the outer element; visual animation should move to a child. |
| Elastic + Feedback | Browser reproduction confirms that Feedback keyframes mask an active inline elastic transform. The same resource diagnostic applies. |
| Elastic + Present transform | A held elastic inline transform prevents Present's requested transform from taking effect. Development mount/update diagnoses the incompatible declarations. |
| Present + Feedback | Both replace the same transform when Feedback targets a Present transform element. The actual Feedback effect is checked against Present's persistent transform declaration. Opacity-only Present remains compatible. |
| Snap + item transforms | The existing `2020` catalog entry had no emission. Development mount/update now checks the eligible item's effective transform, including individual translate/rotate/scale properties. Nested Scrollboxes and disabled Snap are excluded. This warns about geometry coupling, rather than claiming that every static transform produces a wrong snap destination. |
| Present + initially hidden Snap | The browser scenario passes without a change: revealing Present aligns the first item with a nonzero initial offset. No new warning or visibility mechanism was added. |
| Item resize + Snap | Reproduced stale `--ae-snap-viewport` after resizing an item while keeping the box unchanged. Snap now observes eligible item sizes with its existing ResizeObserver and disconnects observations on unmount. This also covers item dimension changes driven by Adaptive/CSS; it does not add an Adaptive-specific dependency. |
| AJAX + State Navigation | Reproduced URL/history changes on network failure, absent response regions and total unmount veto. History is now requested once, immediately before the first accepted replacement. Superseded responses cannot replace current content or push stale history. |
| AJAX + BeforeUnmount | Partial replacement is already the documented lifecycle contract. It remains supported: accepted regions change, vetoed regions remain, and successful partial replacement creates one history entry. |
| AJAX + Feedback | Corrected reversed message/target arguments in busy/progress calls; integration coverage checks payloads and absence of argument errors. |
| Point + Scrollbox pointer | Browser integration confirms that Point keeps tracking the press while Scrollbox consumes drag movement, then clears pressed state at release. No additional warning was justified. |
| Anchor + elastic ancestor | Source already checks the positioning reference (`1119`) and converts scaled reference rectangles into local coordinates. No universal incompatibility is inferred from an elastic ancestor alone. Arbitrary transformed ancestor/reference combinations remain outside the new resource detector's same-element scope. |

## Detection boundary

The shared resource helper derives persistent writers from current behavior state; it does not maintain a parallel ownership registry. CSS Motion inspects actual new effect keyframes in development, for both controlled and native execution when the browser exposes them. Additive effects, opacity-only effects, pseudo-elements, separate child targets and production are excluded. Native animation completion retains its existing semantics; diagnostic capture does not take control of pre-existing animations.

The complete browser run also exposed stale Full bundle test expectations: their source regex recognized only `AelluxJs.extAttach`, excluding Overflow Marquee's existing `api.extAttach` registration, and their fixed lazy list omitted it. The test now uses the explicit official catalog and includes Marquee among the independent lazy Extensions; runtime loading policy is unchanged.

Warnings preserve the requested behavior and include a correction. They do not merge transforms, suppress an animation or establish atomic transactions across AJAX regions. Changes in CSS outside mount/update and animations outside CSS Motion are not continuously scanned.

## Validation

Focused integration scenarios cover Chromium, Firefox and WebKit, controlled/native motion, negative cases and minified Modern/Legacy bundles.

- `npm run build`: passed; final documentation regeneration also passed after recording bundle measurements.
- `npm run test:unit`: 51 passed.
- Complete browser matrix: 1,906 passed, 32 existing skips and 12 failures confined to the stale Full bundle expectations described above. All 12 expectations were corrected and revalidated in the final run.
- Final browser run on the rebuilt artifacts (`extension-composition`, `full-bundle`, `css-motion`, `present-enhancements`): 165 passed, 3 existing skips, zero failures across Chromium, Firefox and WebKit. This includes all 57 composition cases and the 12 corrected Full expectations.
- `npm run test:budget`: passed. Only four affected Orchestrator/Full limits changed; exact previous/current limits and raw/gzip deltas are in the diagnostics guide. Boot/ESM and independent Extension limits were retained.
- `npm pack --dry-run --ignore-scripts --json`: passed, 152 package entries. Build was completed separately before this check.
- `git diff --check`: passed. Dependency manifests were unchanged. The user's pre-existing Docweaver template edit was preserved and propagated through normal documentation generation.

The Windows sandbox's esbuild path-resolution failure and npm cache `EPERM` were resolved by rerunning those commands with the required access. They were not classified as product failures.
