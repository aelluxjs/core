# Focus Extension

Register `focus` separately with `AelluxJs.ext("focus")`. It is not included in the `full` bundle.

`data-ae-focus="next"` adds `enterkeyhint="next"` to text-entry inputs, textareas and editable elements when `enterkeyhint` is absent. An explicit hint is preserved. It changes the mobile keyboard's Enter key label, not the focus order or Enter key behavior.

The Extension observes `focusin`, capture-phase `focus` and `blur` on the document, and `focus` and `blur` on the window. A blur preserves the last valid element target; repeated notifications for the same element do not create duplicate history entries. Focus changes are recorded in a bounded, in-memory history. Call `AelluxJs.ext.focus.restoreLastFocus()` to focus the previous connected, visible target. It returns `true` if focus moved and `false` when no valid target remains. Hidden, inert, disabled and detached targets are skipped.

When Present dispatches `AelluxJsUnpopFocusLost` after hiding a region containing the active element, Focus attempts to restore the previous valid target from its history. Ordinary blur events do not trigger automatic restoration.

Each recorded focus change emits `AelluxJsPushState` with `detail: { key: "ae-focus", value: token }`. The Focus Extension does not access `state-navigation` directly. When State Navigation is loaded, it consumes that event and records the token in its snapshot; `AelluxJsSnapshotRestore` then lets Focus restore the target if it remains valid. Without State Navigation, the event remains available to another consumer and Focus continues to maintain its local history.

This integration works within the current document lifetime; focus tokens do not survive a page reload. With the default hash navigation setting, recorded focus changes also change the hash. Set `useHash: false` in the Core options if that URL behavior is unwanted. Unmount removes an `enterkeyhint` generated by Focus while preserving a value originally declared by the application.

The Extension does not trap focus or announce navigation changes. Applications remain responsible for suitable focus order and accessible controls.
